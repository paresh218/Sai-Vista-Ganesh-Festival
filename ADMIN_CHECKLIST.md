# Sai Vista Festival — committee publishing checklist

This template is safe to keep with the website because it contains no private values. Keep real passwords, resident data, payment references, and private receipt files outside the published website folder.

## Before publishing an update

- [ ] Confirm the event date, time, location and committee contact.
- [ ] Update `site-data.js` for a Today card or committee update.
- [ ] Remove expired updates; keep only information residents still need.
- [ ] Check English, Hindi and Marathi wording.
- [ ] Verify every public form link and WhatsApp link.
- [ ] Confirm that no resident name, flat number, phone number, email, UPI reference or payment status appears publicly.

## Festival schedule and forms

- [ ] Confirm the schedule artwork and written schedule match.
- [ ] Update the relevant Google Form URL in `index.html` if it changes.
- [ ] Confirm whether each registration form should be enabled or disabled.
- [ ] Test one mobile and one desktop browser after an update.

## Before sharing the site

- [ ] Check the Today card, latest updates and Aarti availability.
- [ ] Check the language selector and keyboard navigation.
- [ ] Reload the installed app/PWA once so it receives the latest version.
