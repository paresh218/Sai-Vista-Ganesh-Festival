# Sai Vista — Aubergine Atelier

Shared theme for the existing vanilla HTML/CSS/JS community portal. Replaces the rejected evergreen and cobalt candidates; retains Outfit / Work Sans.

## Verified references
- UI/UX Pro Max: community portal premium spatial search matched Spatial UI. Adapt depth without making navigation immersive or hiding the CTA behind animation.
- 21st.dev Modern Minimal: https://21st.dev/@serafimcloud/themes/modern-minimal (read 29 October 2026). White/slate surfaces with a blue primary. Adapted darker cobalt for white-text contrast; no component source was retrieved or copied.
- Official 21st CLI 1.18.0 installed as a development dependency; official Codex plugin 0.5.0 installed. Search returned authentication required. No paid generation or private data upload.
